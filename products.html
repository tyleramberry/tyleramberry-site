Grant & RFP agent platform

A full-stack app for a grant-writing and government-contracting client. An orchestrator reads each request, sends it to the right specialist agent, and every agent shares one project memory.

PProblem

Grant and contracting work is mostly reading: eligibility rules, long RFPs, compliance checklists. Those are the parts a model can draft, but only if it keeps the client's context straight across many projects. [PLACEHOLDER: the client's before-state in one line]

DDecisions

  • Orchestrator plus specialists instead of one do-everything agent: grant specialist, contracting specialist, business assistant, personal agent.

03 Consumer SaaS

Sundae Planner

An AI weekly-planning coach. You talk through the roles you play in life, it helps you plan actions for each one, puts the plan on your Google Calendar, and checks in every day.

Live in production
sundaeplanner.com Placeholder thumbnail · add img/sundae.jpg

PProblem

Weekly planning works when you do it, and almost nobody keeps doing it. Planner apps hold your list but never ask you about it, so the plan and the week drift apart by Tuesday.

DDecisions

  • Nothing touches your calendar until you approve it. The AI proposes; you confirm.
  • One function decides "done." Every screen shows the same score because only one piece of code computes it.
  • Channel-agnostic engines. Web, email, and text can all use the same conversation brain.

OShipped

  • A conversational weekly session that ends in confirmed calendar blocks.
  • A daily cron that follows up by email and reconciles goals against what happened.
  • Onboarding, trials, Stripe billing, analytics, and a custom domain. 114 commits in its first stretch, from Aug 4, 2026.

04 Personal AI system

Personal agent harness

A personal operating system I own: a markdown library of everything I know, skills (written procedures an agent follows), scheduled jobs, and a team of agents that ships software.

PProblem

Every new chat starts from zero. I was re-explaining my classes, my clients, and my finances to a model that forgot them by the next session, and doing the same tasks by hand over and over.

DDecisions

  • Context lives on disk, in plain markdown I can read and edit, not inside one vendor's memory.
  • Do it once by hand, then make it a skill. Daily briefs, meeting prep, class notes, and inbox triage all started that way.
  • Models judge, code calculates. The household CFO agent never invents a number; scripts do the math.
  • People decide, agents do. Shipping code, writing to a calendar, or spending money waits for a human.

OShipped

  • Buzz software factory: Tyler scopes → Greg writes the PRD → Brad builds and runs types, lint, build → Quinton QAs against six repo rules → ship.
  • Household CFO agent: bank exports in, budget buckets, weekly check-ins, a monthly "money date."
  • Runs on Claude Code, Codex, or Hermes, with an always-on Mac Mini for long jobs.

Markdown + Obsidian · Claude Code · Codex · Hermes · cron · Python · MCP

05 MSB 341 product · BYU Marriott

Homeroom → MySI

Homeroom began as an education-focused agent harness: your syllabi, deadlines, and rubrics in, a tutored and rubric-checked draft out. Discovery pushed it somewhere better: MySI, a benchmark built from your own work.

MySI prototype live
Try MySI

PProblem

A model can only help with what it can see, and a student's world lives in an LMS, in PDFs, and in their head. Separately, leaderboards test math olympiads, not the things people actually ask AI to do, so nobody knows which model is best for them.

DDecisions

  • 001: Students first. I'm one, so I can test it on my own courses every day.
  • 002: Portfolio first, not a B2B sale. No school procurement in the way of one working loop.
  • Don't build the harness core. The agent loop is solved; the value is the domain layer on top.
  • Pivot. Interviews showed the study-tool problem was weak, so I moved to MySI.

OShipped

  • Homeroom PRD, MVP spec, decision log, and a v0 app.
  • MySI: an MCP connector that interviews you, builds test tasks from your real work, runs them on GPT, Gemini, and Claude, and has you rate them blind.
  • First outside tester: interview to ranking in about 15 minutes, for $0.07. Their three-way tie led to a rule: ties go to the cheaper, faster model.

TypeScript · Vite · Cloudflare Workers · Supabase · MCP · OpenAI, Gemini & Claude APIs
