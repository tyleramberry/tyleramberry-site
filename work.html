Claude CodeHermesCodex

The operating system I run my life and work on, which is also my R&D lab.

A markdown second brain, reusable skills, scheduled jobs, and a team of agents. Everything above runs through it. It isn't a business; it's how I learn what agents can actually do before I put them in front of a client.

Logshipped · decided · learned
  • ShippedSecond brain: 113 linked knowledge pages, 23 agent skills, 7 scheduled jobs. Every session starts by reading one router file.
  • ShippedBuzz software factory: nine agents that take a Sundae feature from PRD to build to QA to ship, with a QA gate nobody skips.
  • ShippedRemote worker: an always-on Mac Mini that agents hand long or browser-heavy jobs to while my laptop is closed.
  • DecidedModels judge, code calculates. The household CFO agent never invents a number: scripts do the math, and rows it can't read go to a review list.
