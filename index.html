Sundae Planner

An AI weekly-planning coach. You talk through the roles you play in life, it helps you plan actions for each one, then puts the plan on your Google Calendar. A daily check-in follows up and keeps score.

Agent · Built on the second brain

Household CFO agent

A budgeting agent for my family. It pulls in bank, Venmo, and Mercury exports, sorts every transaction into a budget bucket, runs weekly check-ins and a monthly "money date," and answers "can we afford this?" by text.

Design principles

  • Never invents a number. Rows it can't read go to a review list instead of being guessed.
  • Python scripts do all the math. The model only handles conversation and judgment calls.
  • Everything is CSV and markdown that a person can read and edit.

Rhythm

  • Weekly: pace, overspending, and bills due in the next 14 days
  • Monthly: set each bucket's budget, audit subscriptions, sync bills to the calendar
  • Quarterly: big-picture review plus estimated-tax reminders

Python · iMessage (AppleScript) · Google Calendar · Markdown dashboards

02 How I build

Proof over "it compiled"

It isn't done until it's running and I've watched it work: types, lint, a build, and a real test in the product.

People decide, agents do

Anything that matters, like writing to a calendar, shipping code, or spending money, waits for a person to approve it.

Models judge, code calculates

LLMs handle language and judgment. Arithmetic, scheduling, and anything that needs an exact answer goes to deterministic code.

Process is a product

Specs, handoffs, and QA gates are what let a team of agents ship safely instead of creating chaos.
